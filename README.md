# 天天象棋学习助手

一个面向 Windows 的独立象棋学习助手。它计划从微信天天象棋窗口读取棋盘画面，在本地维护经过规则验证的镜像局面，使用 Pikafish 给出分析，并通过 DeepSeek 把引擎证据解释成可追问的中文教学建议。

## 当前状态

`develop` 分支正在按“风险探针 → 垂直闭环 → 再增强”路线开发。当前已经具备象棋规则内核、窗口级 Windows Graphics Capture 与手工标定、连续多步监听、严格的单步证据门、镜像棋盘同步、可取消的 Pikafish MultiPV 两阶段分析、独立分析窗口，以及证据约束的本地/DeepSeek 教练。捕获后端以 20 FPS 提供窗口帧，稳定期只处理约 2 FPS，发现画面变化后临时处理完整帧率。视觉同步仍处于真实小样本验收期：已确认局面会在固定主题下建立内存模板，不能唯一解释或置信不足的变化会暂停并保留最后确认局面；Stage C 冻结盲测通过前，视觉落子不会自动触发 Pikafish。

## 当前开发版运行

```powershell
.\.venv\Scripts\python.exe scripts\install_pikafish.py
.\.venv\Scripts\python.exe -m xiangqi_agent
```

窗口启动后显示标准初始棋盘，也可以手工输入 FEN。“可见窗口捕获与四角标定”区域可刷新并连接当前可见、未最小化的天天象棋窗口；连接成功后显示实际帧尺寸和 90 个交点。等比例缩放会安全重绑几何，比例明显变化则暂停并要求确认 FEN。只有画面稳定且唯一合法一步通过全部证据门时，镜像棋盘才会更新；歧义变化不会污染已确认局面。手工载入 FEN 时，如捕获正在运行，会先等待新的稳定画面再事务式恢复。手工分析先显示 500ms 快速三候选，再用 3000ms 加深结果覆盖。“教练”页在没有 API Key 时使用本地证据模板；也可以通过“DeepSeek 设置”把 Key 安全存入 Windows Credential Manager。界面不会回显既有 Key，截图不会发送给 DeepSeek。

## 使用边界

- 仅用于人机练习、残局训练和赛后复盘。
- 不模拟点击、不自动落子，也不控制微信或天天象棋。
- 不支持真人在线对局中的实时辅助。
- 引擎负责走法与评分的正确性；DeepSeek 只解释已验证证据。
- API Key、完整截图、用户数据库和诊断资料不会进入 Git 仓库。
