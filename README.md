# 天天象棋学习助手

一个面向 Windows 的独立象棋学习助手。它计划从微信天天象棋窗口读取棋盘画面，在本地维护经过规则验证的镜像局面，使用 Pikafish 给出分析，并通过 DeepSeek 把引擎证据解释成可追问的中文教学建议。

## 当前状态

`develop` 分支正在按“风险探针 → 垂直闭环 → 再增强”路线开发。当前已经具备象棋规则内核、可见窗口捕获与手工标定、严格的单步证据门，以及可取消的 Pikafish MultiPV 两阶段分析。视觉同步仍处于真实小样本验收期，未达到数据门之前不会静默更新棋盘。

## 使用边界

- 仅用于人机练习、残局训练和赛后复盘。
- 不模拟点击、不自动落子，也不控制微信或天天象棋。
- 不支持真人在线对局中的实时辅助。
- 引擎负责走法与评分的正确性；DeepSeek 只解释已验证证据。
- API Key、完整截图、用户数据库和诊断资料不会进入 Git 仓库。

## 路线图

1. 已完成：领域内核、可见窗口捕获、手工四角标定和 90 点几何。
2. 进行中：基于合法下一步枚举的严格视觉证据门与真实样本验收。
3. 已完成内核：Pikafish 固定资产安装、独立 UCI 进程及渐进式 MultiPV 分析。
4. 下一步：把捕获、确认局面和分析接成最小独立窗口闭环。
5. 后续：DeepSeek 证据约束教学解释、复盘和 Windows 交付增强。
