# 天天象棋学习助手

一个面向 Windows 的独立象棋学习助手。它计划从微信天天象棋窗口读取棋盘画面，在本地维护经过规则验证的镜像局面，使用 Pikafish 给出分析，并通过 DeepSeek 把引擎证据解释成可追问的中文教学建议。

## 当前状态

`develop` 分支正在按“风险探针 → 垂直闭环 → 再增强”路线开发。当前已经具备象棋规则内核、可见窗口捕获与手工标定、严格的单步证据门、可取消的 Pikafish MultiPV 两阶段分析，以及可启动的独立分析窗口。视觉同步仍处于真实小样本验收期，未达到数据门之前不会静默更新棋盘。

## 当前开发版运行

```powershell
.\.venv\Scripts\python.exe scripts\install_pikafish.py
.\.venv\Scripts\python.exe -m xiangqi_agent
```

窗口启动后显示标准初始棋盘，也可以手工输入 FEN。点击“载入局面并分析”后，先显示 500ms 快速三候选，再用 3000ms 加深结果覆盖。引擎缺失或 FEN 非法时会给出提示，不影响窗口安全退出。

## 使用边界

- 仅用于人机练习、残局训练和赛后复盘。
- 不模拟点击、不自动落子，也不控制微信或天天象棋。
- 不支持真人在线对局中的实时辅助。
- 引擎负责走法与评分的正确性；DeepSeek 只解释已验证证据。
- API Key、完整截图、用户数据库和诊断资料不会进入 Git 仓库。
