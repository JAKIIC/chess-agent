# 天天象棋学习助手

一个面向 Windows 的独立象棋学习助手。它计划从微信天天象棋窗口读取棋盘画面，在本地维护经过规则验证的镜像局面，使用 Pikafish 给出分析，并通过 DeepSeek 把引擎证据解释成可追问的中文教学建议。

## 当前状态

`develop` 分支正在按“风险探针 → 垂直闭环 → 再增强”路线开发。当前已经具备象棋规则内核、可见窗口捕获与手工标定、严格的单步证据门、可取消的 Pikafish MultiPV 两阶段分析、独立分析窗口，以及证据约束的本地/DeepSeek 教练。视觉同步仍处于真实小样本验收期，未达到数据门之前不会静默更新棋盘。

## 当前开发版运行

```powershell
.\.venv\Scripts\python.exe scripts\install_pikafish.py
.\.venv\Scripts\python.exe -m xiangqi_agent
```

窗口启动后显示标准初始棋盘，也可以手工输入 FEN。“可见窗口捕获与四角标定”区域可刷新并连接当前可见、未最小化的天天象棋窗口；连接成功后显示实际帧尺寸和 90 个交点，窗口尺寸变化时要求重新标定。该连接目前只报告捕获状态，不会在真实样本门通过前自动更新局面。点击“载入局面并分析”后，先显示 500ms 快速三候选，再用 3000ms 加深结果覆盖。“教练”页在没有 API Key 时使用本地证据模板；也可以通过“DeepSeek 设置”把 Key 安全存入 Windows Credential Manager。界面不会回显既有 Key，截图不会发送给 DeepSeek。

## 使用边界

- 仅用于人机练习、残局训练和赛后复盘。
- 不模拟点击、不自动落子，也不控制微信或天天象棋。
- 不支持真人在线对局中的实时辅助。
- 引擎负责走法与评分的正确性；DeepSeek 只解释已验证证据。
- API Key、完整截图、用户数据库和诊断资料不会进入 Git 仓库。
