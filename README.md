# 天天象棋学习助手

一个面向 Windows 的独立象棋学习助手。它计划从微信天天象棋窗口读取棋盘画面，在本地维护经过规则验证的镜像局面，使用 Pikafish 给出分析，并通过 DeepSeek 把引擎证据解释成可追问的中文教学建议。

## 当前状态

项目处于 `v0.1.0-m0` 仓库基线阶段：设计与实施路线已经确定，业务代码尚未开始发布。每个后续里程碑只有在自动测试、独立评审和隐私检查通过后才会推送到 `develop` 分支。

## 使用边界

- 仅用于人机练习、残局训练和赛后复盘。
- 不模拟点击、不自动落子，也不控制微信或天天象棋。
- 不支持真人在线对局中的实时辅助。
- 引擎负责走法与评分的正确性；DeepSeek 只解释已验证证据。
- API Key、完整截图、用户数据库和诊断资料不会进入 Git 仓库。

## 路线图

1. M1：领域内核、桌面窗口、目标窗口捕获与棋盘标定。
2. M2：棋子识别、多帧稳定和可靠镜像同步。
3. M3：Pikafish 两阶段局面分析。
4. M4：DeepSeek 证据约束的教学解释。
5. M5：本地复盘、恢复、Windows 打包和真实验收。

详细设计和执行计划位于 [`docs/superpowers`](docs/superpowers)。当前里程碑状态记录在 [`docs/status`](docs/status)。
