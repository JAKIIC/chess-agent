# 棋盘缩放自动适配状态（2026-08-31）

## 结论

监听链路现已支持目标窗口的等比例或近似等比例缩放。原四角标定使用归一化坐标重绑定到新画面，稳定输出 90 个交点；缩放后还会用最后确认局面的固定主题模板逐点验证，只有 90 个位置仍与原局面一致时才继续监听。

## 安全行为

- 缩放前后宽高比相对变化不超过 2%：尝试自动适配。
- 缩放后局面、主题或棋盘布局不一致：保留最后确认局面并进入 `CONTEXT_INVALID`，不静默重置基线。
- 缩放与落子同时发生：因为至少起点、终点语义不一致，自动适配被拒绝，需要人工恢复。
- 宽高比变化超过安全范围：拒绝自动适配并提示重新标定。
- 捕获采样器会把尺寸变化作为显式事件交给同步层，不会把新尺寸帧混入旧尺寸动画序列。
- 如果缩放被拒绝，人工恢复必须同时提供新局面、新画面和与新尺寸匹配的几何标定；恢复后可以继续监听后续着法。
- 默认不保存完整截图。

## 当前限制

第一版仍要求窗口可见、无遮挡。当前自动适配覆盖窗口等比例缩放、最大化/还原中宽高比近似不变的情况；如果应用内部缩放导致棋盘在窗口内重新排版，或窗口宽高比发生较大变化，会安全暂停。后续可在不改变 `BoardGeometry` 和 `StableMoveTracker` 契约的前提下加入基于图像配准的重新定位。
