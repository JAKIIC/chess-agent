# 隐私诊断与保留期状态

**日期：** 2026-09-01

**分支：** `develop`

**状态：** 端点小块记录与自动过期清理已完成；产品设置入口尚未接入

## 已完成边界

- 诊断记录默认关闭；未显式启用时不创建目录或图片。
- 显式启用后，每个样本只保存走子起点和终点在变化前后的四个 48×48 BGRA PNG。
- 记录器拒绝尺寸不同的图片，因此完整窗口、完整棋盘和普通截图不能进入该路径。
- 清单不含窗口标题、API Key 或完整 DeepSeek 请求；会话和样本标识必须通过路径安全校验。
- 默认容量上限为 256 MiB，超过上限时整条新样本拒绝，不留下半写目录。
- 默认保留期为 7 天，可使用非负整数配置；每次显式写入新样本时按样本 UTC 时间
  自动清理过期样本，也可用带时区的 UTC 时钟主动清理。
- 无清单、清单损坏或时间字段无效的未知目录不会被自动删除，避免误删非本程序数据。

## 当前限制

- 这一路径当前只供显式运行的视觉证据探针使用，尚未在普通用户界面提供开启开关。
- 端点样本用于调试视觉门，不是棋局复盘数据库，也不保存完整局面图片。
- SQLite 会话复盘、环境自检和 Windows 打包仍未完成。
