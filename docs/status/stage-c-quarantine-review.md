## 捕获与占用算法

- 默认后端为窗口级 Windows Graphics Capture（`windows-capture==2.0.1`），本机真实
  帧为 `2313×1385`，窗口候选的逻辑客户区为 `1539×922`，对应 150% DPI。
- 原桌面级 DXGI 可见窗口裁切在该 DPI 环境中取到了错误区域，已从 Stage C 默认路径移除；
  它仍保留为可替换探针后端，不作为当前现场门依据。
- 占用算法版本为 `known-position-template-occupancy-v1`。它只在内存中从用户确认的
  `BoardState` 和固定主题画面提取空位/有子模板特征，不保存完整帧或完整棋盘。
- 初次校准必须让 90 个预测占用与确认局面完全一致，并达到最小模板分离度；否则 90 点
  全部返回低置信并拒绝建立基线。
- 当前限制：只支持标准初始局面或用户提供且确认的 FEN；窗口必须可见、无遮挡；主题在
  会话中固定；尺寸或长宽比发生不安全变化时关闭本次采集并要求重新连接。
