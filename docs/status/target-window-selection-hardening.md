# 目标窗口选择加固（2026-08-31）

## 问题

真实冒烟中，窗口目录曾把普通微信主窗口识别为天天象棋候选。该窗口的进程名符合旧筛选条件，但标题不是“天天象棋”；继续捕获会造成错误几何、全局变化和隐私风险。

## 修复

- 顶级窗口必须可见、未最小化、客户区有效，并且标题明确包含“天天象棋”。
- 不再仅凭 `Weixin.exe`、`WeChat.exe` 或 `WeChatAppEx.exe` 进程名接受候选。
- 手工选择仍必须从经过筛选的候选集合中解析，不会回退到普通微信窗口。

## 真实结果

加固后普通微信主窗口被排除。当前真实天天象棋窗口处于最小化或不可见状态，因此目录正确返回零个候选；待用户手工恢复窗口后再进行只读真实单步验收。
