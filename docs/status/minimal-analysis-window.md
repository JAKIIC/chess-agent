## 1. 当前能力

- 启动后显示标准初始棋盘。
- 接受标准中国象棋 FEN，并在提交前通过规则层验证双方将帅和合法走法能力。
- 使用独立棋盘控件绘制 90 个交点、楚河汉界、九宫和红黑棋子。
- 候选表显示中文记谱、红方视角评分、深度、主要变化和 UCI 坐标。
- 快速结果到达后立即显示；加深结果到达后原位覆盖。
- 新 FEN 会触发旧分析停止，旧局面的回调不会进入界面。
- 引擎未安装时显示本地安装指引并禁用分析按钮。
- FEN 非法或引擎报错时暂停分析，不改变最后确认棋盘。
- 窗口关闭时有界停止分析并关闭 Pikafish，不遗留进程。

## 2. 中文字体兼容

真实离屏冒烟第一次显示为方框。根因是当前 PySide6 离屏平台未自动发现 Windows
字体目录，而不是字符串编码损坏。应用现在显式注册系统微软雅黑，并把它设为应用字体；
自动测试用 `QFontMetrics` 验证“棋”字确实存在于字体中。第二次截图中的标题、棋子、
中文记谱和变化线均正常显示。

两张调试截图只位于 Git 忽略的 `.local/` 目录，不进入仓库。
